Plataforma de Gestão Acadêmica

Painel para gerenciar alunos, cursos e boletins, com cálculo automático de média e situação. Esta tela é o front-end (HTML5/CSS3/JS puro) com dados de demonstração em memória; ele foi feito para consumir a API REST em PHP/MySQL incluída no projeto (pasta backend/), que também alimenta o script de relatórios em Python e o módulo desktop em C#.

Disciplina Nota

Em produção, este relatório é gerado pelo script scripts/relatorio_desempenho.py (lendo direto do MySQL) ou pelo módulo desktop em C#. Aqui, o botão abaixo gera a mesma estrutura de relatório em CSV a partir dos dados desta página, para demonstração.

Sobre a stack deste projeto

  • Front-end (aqui): HTML5, CSS3 e JavaScript puro, sem frameworks.
  • Back-end: API REST em PHP consultando um banco MySQL — ver pasta backend/.
  • Automação de relatórios: script Python que lê o banco e exporta CSV/resumo — ver pasta scripts/.
  • Módulo desktop: aplicação complementar em C# para consulta rápida de alunos em situação crítica — ver pasta desktop/.
